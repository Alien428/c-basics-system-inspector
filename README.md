# c-basics-system-inspector

Small C program written to practice core language concepts and memory basics.

## Overview
- Data types & size checks (`sizeof`)
- Pass-by-reference using pointers
- Array traversal with pointer arithmetic
- Custom structs

## Notes
- Using explicit `int main(void)` for clarity.
- Focus is on practicing manual pointer operations and basic memory mechanics.

```bash
gcc system_inspector.c -o system_inspector
